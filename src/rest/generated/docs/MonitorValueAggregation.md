
# MonitorValueAggregation

How the values in a window are reduced before comparison: `Max`, `Min`, `AvgOf` and `SumOf` compare the largest, smallest, mean or total. The older `AllOf` and `AnyOf` require every or at least one value to match; new monitors use `Min` or `Max` instead.
